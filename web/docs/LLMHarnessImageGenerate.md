# API图像生成

使用自己配置的图片服务，根据提示词生成图片。属于 `llm_harness/image`，与「LLM 远程回复」共用来源管理。

## 第一次使用

1. 点击节点上的 **添加 / 编辑来源**，在 ComfyUI 所在电脑弹出的窗口中配置来源名称、Endpoint、API Key 和图片模型名称。
2. Endpoint 填 API 基础地址，例如 `https://example.com/v1`。节点会追加 `/images/generations`，不要在基础地址中重复填写这个后缀。
3. 保存后点击 **刷新来源**，选择来源和模型，填写提示词，再把 IMAGE 输出连接到预览或保存图片节点。

来源中的「API 格式」只影响文字节点；本节点始终调用图片生成接口，不会切换到 Chat、Responses 或 Anthropic 消息接口。模型列表由来源配置决定，请填写服务实际支持的图片模型名。

## 参数和输出

- **提示词**：描述要生成的内容。
- **尺寸**：请求服务输出的尺寸；`auto` 由服务决定。可用尺寸取决于服务和模型。
- **质量**：`auto` 不发送质量字段，由服务使用默认值；其余选项直接发送。
- **超时（秒）**：请求建立连接最多等待 20 秒，此参数控制读取响应时连续收不到数据的等待时间，并非整次任务的绝对时限。
- **重新生成**：默认关闭，复用本次 ComfyUI 启动以来相同输入的结果；开启时重新请求并在成功后更新缓存。
- **IMAGE**：一次调用返回一张 RGB 图片张量。输入执行列表时，ComfyUI 会按列表规则分别调用。

生成节点与包内其他生成式节点共用 SHA-256 会话缓存。来源、地址、Key、模型、提示词、尺寸、质量或超时变化都会匹配到不同记录；A→B→A 可以取回 A 的结果，相同输入在同类节点之间也可复用。图片以压缩 PNG 保存在内存，重启 ComfyUI 后清空；失败或中断不会覆盖已有成功结果。

请求使用 JSON，服务应返回 `data[0].b64_json` 或 HTTPS 图片地址 `data[0].url`。

## 来源和错误处理

Key 保存在本机来源配置中，不写入节点参数或工作流。来源编辑会同时影响使用该来源的文字及图片节点；需要独立配置时请新建一个来源。原 mxwq 包中的节点和配置保持独立。

超时不等于服务端取消；请核对服务记录后再重跑，节点不会自动重试生成。API 来源支持范围、模型权限和计费规则以所选服务为准。
